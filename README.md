# 🤖 AI 아이디어 토론방

아이디어 하나 던지면 **AI 4명이 서로 토론해서 결론까지 내주는** 모바일 웹앱입니다.
무료 Gemini API 키만 있으면 설치 없이 브라우저에서 바로 씁니다.

## 4명의 패널

| 역할 | 하는 일 |
|---|---|
| 💡 아이디어맨 | 과감한 아이디어, 숨은 기회 발굴 |
| 🧐 현실주의자 | 비용·시간·인력·리스크 냉정 점검 |
| 🥊 반대파 | 허점·실패 시나리오 집중 공격 |
| 👑 팀장 AI | 논점 정리 + 마지막 라운드 후 **최종 결론 & 추천 액션 3가지** |

역할은 각각 켜고 끌 수 있고, 성격 문구를 직접 고쳐 말투와 관점을 바꿀 수 있습니다.

## 쓰는 법

1. 주제를 적고 **라운드(1~3)** 를 고릅니다.
2. `토론 시작` → AI들이 앞선 발언을 이어받아 **한 명씩 실시간 스트리밍**으로 말합니다.
3. 토론 중/후에 아래 입력창으로 **끼어들기**(질문·반박·방향 전환)가 가능합니다.
4. `복사` 로 전체 토론을 마크다운으로 복사, `📚` 에서 지난 토론을 다시 엽니다.

## API 키

- 키 발급: https://aistudio.google.com/apikey (Google 계정만 있으면 무료, 카드 등록 없음)
- 키는 **오직 사용자 브라우저의 `localStorage`** 에만 저장됩니다. 이 저장소나 서버에는 키가 없습니다.
- **모델은 자동으로 찾습니다.** 키를 저장하면 `GET /v1beta/models` 로 그 키가 실제로 `generateContent` 할 수 있는 모델 목록을 받아와 드롭다운을 채우고, 가장 알맞은 Flash(예: `gemini-3.8-flash`)를 자동 선택합니다. 구글이 모델을 은퇴시키거나 갈아치워도 따로 고칠 필요가 없습니다.
- 그래도 `404`(모델 없음)가 나면 목록을 새로 받아 다음 후보 모델로 **자동 폴백 재시도**하고, `thinkingConfig` 가 거부(`400`)되면 그 설정 없이 다시 시도합니다.
- 원하면 설정의 `↻` 로 목록을 다시 확인하거나, 드롭다운에서 직접 모델을 고를 수 있습니다.
- 키가 없어도 **샘플 데모 재생**으로 화면과 흐름을 미리 볼 수 있습니다.

## 파일

- `index.html` — 앱 전체(HTML/CSS/JS 단일 파일, 외부 라이브러리 0개)
- `sw.js` — 캐시 세대(`adr-shell-v3-…`)를 올리고, 화면 요청은 네트워크 우선(`cache: no-store`)으로 처리해 폰에 옛 `index.html` 이 남지 않게 함
- `.nojekyll` — GitHub Pages Jekyll 처리 생략
